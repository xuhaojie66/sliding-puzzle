## 二、部署服务器：Cloudflare Pages

### 是什么

本项目托管在 **Cloudflare Pages** 上。它是 Cloudflare 提供的**静态站点托管服务**，
不是传统意义上"一台服务器"，而是把构建产物（`dist/` 目录里的 HTML/CSS/JS/图片）
分发到 Cloudflare 遍布全球的 **边缘节点（CDN）**，用户访问时就近由最近的节点返回，
天然带 HTTPS、免运维、免费额度充足。

### 为什么选它

- **国内可访问**：`*.pages.dev` 在国内访问稳定，而 `*.vercel.app` 被墙。
- **免费**：个人项目免费额度足够。

## 三、域名是怎么来的

本项目的域名 `sliding-puzzle-ay2.pages.dev` 是 **Cloudflare 自动分配的免费二级域名**，
不是自己购买的。生成规则如下：

```
sliding-puzzle          -ay2          .pages.dev
└── 项目名（自定义）      └── 随机后缀   └── Cloudflare 的固定根域名
                         （创建项目时
                          自动生成，防重名）
```

- **`pages.dev`**：Cloudflare Pages 所有站点共用的根域名。
- **`sliding-puzzle`**：创建 Pages 项目时指定的项目名。
- **`-ay2`**：Cloudflare 在项目创建时自动追加的随机短后缀，用于避免不同用户之间的
  项目名冲突。这个后缀一旦生成就固定不变，因此正式地址长期稳定。

### 每次部署还会有一个"预览地址"

除了固定的正式地址，Cloudflare 每次部署都会额外生成一个带哈希前缀的一次性预览地址，
形如：

```
https://<本次部署哈希>.sliding-puzzle-ay2.pages.dev
例如：https://a16ae420.sliding-puzzle-ay2.pages.dev
```

预览地址用于回溯某一次具体的部署版本；日常对外分享用**正式地址**即可。

### HTTPS 证书

`pages.dev` 域名的 HTTPS 证书由 Cloudflare 自动签发和续期，无需任何手动配置。

## 四、自动部署链路（推代码即上线）

代码仓库与 Cloudflare Pages 已打通自动部署。整体链路：

```
本地改代码
   │  git push 到 main 分支
   ▼
GitHub 仓库 (xuhaojie66/sliding-puzzle)
   │  触发 GitHub Actions
   ▼
GitHub Actions 工作流 (.github/workflows/deploy.yml)
   ├─ 用 pnpm 安装依赖（秒级）
   ├─ vite build 构建出 dist/
   └─ wrangler pages deploy dist  → 推送到 Cloudflare Pages
   ▼
Cloudflare Pages 全球边缘节点更新
   ▼
https://sliding-puzzle-ay2.pages.dev 生效（约 20–60 秒）
```

### CI 用到的凭据（存于 GitHub 仓库 Secrets）

| Secret 名 | 用途 |
| --- | --- |
| `CLOUDFLARE_API_TOKEN` | 授权 CI 部署到 Cloudflare Pages（权限：Account · Cloudflare Pages · Edit） |
| `CLOUDFLARE_ACCOUNT_ID` | 指定部署到哪个 Cloudflare 账号 |

> 这些密钥以加密形式保存在 GitHub，不会出现在代码里。

### 手动部署（可选）

如需绕过 CI 手动发一次版，在项目目录执行：

```bash
pnpm install
pnpm exec vite build
pnpm exec wrangler pages deploy dist --project-name=sliding-puzzle --branch=main
```

## 五、关于"国内访问延迟"

`pages.dev` 走的是 Cloudflare 的全球节点，中国大陆访问会有一定延迟，这是**先天限制**，
无法通过改代码根除，只能通过减小资源体积等手段缓解首屏速度。

如果未来对国内访问速度有更高要求，彻底的方案是：

1. **备案一个自己的域名**（如 `example.com`）；
2. 在 Cloudflare Pages 里 **绑定这个自定义域名**（Custom Domain）；
3. 或改用**国内的静态托管 / CDN**（如阿里云 OSS + CDN）以获得国内加速。

在 Cloudflare Pages 绑定自定义域名的入口：
`项目 → Custom domains → Set up a domain`，按提示把域名的 DNS 指向 Cloudflare 即可，
证书依旧自动签发。

## 六、常见问答

**Q：用户上传的图片会传到服务器吗？**
A：不会。上传的图片完全在浏览器本地用 `FileReader` + `Canvas` 处理，不经过任何服务器，
既即时又保护隐私。本站是纯静态托管，也没有后端能接收上传。

**Q：正式地址会变吗？**
A：不会。`sliding-puzzle-ay2.pages.dev` 是固定的，除非删除并重建 Pages 项目
（重建会重新生成随机后缀）。

**Q：怎么下线 / 停用？**
A：在 Cloudflare 控制台删除该 Pages 项目即可；GitHub 仓库可保留或设为私有。
